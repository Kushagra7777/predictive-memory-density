# Related work and the novelty boundary

This file preserves the supplied proposal's overlap assessment. It is **not a new exhaustive novelty search**, and these papers' experiments were not reproduced while assembling this repository. The original PDF's Appendix C records its own inspection depth and access limitations. Recheck the closest papers and public code before asserting a thesis contribution.

The candidate contribution is narrow: **fit a compact, autonomously updating surrogate to clean transformer states, then test whether it predicts held-out partial KV-cache exchange effects better than equally small classical models**. Density validity, decoding a belief, same-next/different-future examples, and cache editing are already established ideas. The pilot may find no density-specific benefit; its true generator requires only one ordinary posterior number plus stage.

No code from the linked projects is required to run this pilot. The implementation here follows the supplied proposal. That does not establish that the idea is globally new or that no comparable implementation exists.

After an encouraging pilot, perform a dated fresh search focused on autonomous predictive summaries, clean-to-intervened transfer, partial-cache swaps, quantum-instrument surrogates, equal-state/parameter/time-budget comparisons, and the closest 2026 sources. Keep what is already known separate from any new measured result.
