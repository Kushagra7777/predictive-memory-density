# Fixed engineering decisions and limits

These choices make the proposal executable. They are not new experimental findings. The fixed pilot settings and thresholds remain those in the PDF; this document distinguishes unspecified details and interpretations.

## Histories, state, and stopping

- Vocabulary IDs are `^:0, 0:1, 1:2, a:3, b:4, ?:5, R:6, $:7`. Padding reuses ID 0 with a separate boolean mask; it is never a learned ninth token and is never a target.
- Nuisance family is the 16-bit integer obtained by interpreting `a=0,b=1`, most significant bit first. Assignment is `int(SHA256(literal_16_character_ab_string).hexdigest(),16) % 100`. All 65,536 families are enumerated before sampling each split. Family ID/hash is metadata only.
- Root sampling round-robins clue, reset status, and base filler delays 0–12, deduplicates full histories, then shuffles. The 52 joint strata cannot divide 20,000 or 4,000 exactly; round-robin counts differ by at most one before deduplication/retry. Fitting batches and per-offset losses balance the four clue/reset strata.
- **Reset-delay ambiguity:** the PDF asks for reset/nonreset roots at delays including zero and defines controls by appending `R`. Here base delay counts the `a/b` fillers; a reset root appends `R` and has one extra actual token. Clue pairs always have the same reset status, actual length, last token, stage, mask, and position. No comparison pretends a reset root and its nonreset root have equal positions.
- Nuisance-family groups are disjoint, not every short prefix. Before clue position 17, shared prefixes are unavoidable and are not scored as analysis examples.
- The true belief becomes 0 or 1 once the answer token is observed. The ridge diagnostic includes distinct clean continuation states as well as initial roots, so this change is represented in its fitting targets. Those targets never enter surrogate inputs or teacher CE.
- **Stopping ambiguity:** §3.1 says `$` is absorbing for every system; A3 describes non-end invalid transitions but does not explicitly list an unexpected `$` from every stage. We apply §3.1 globally: any observed `$` enters STOP. No raw transformer prediction after `$` is used as an endpoint.
- Complete future trees include impossible tokens with whatever mass the trained teacher/surrogate assigns them. INVALID is observable token bookkeeping, not an oracle label. STOP emits only `$`; operations on already stopped rows preserve the compact numeric state.

## Why the reset reference is equal for every future

After an observed `R`, the simulator samples a new fair bit independent of the old bit, the clue, and nuisance tokens. Both paired histories therefore have the same posterior 1/2, same waiting stage, same next-token waiting law, and same transition/answer rules. For any next token with positive probability, their probabilities agree and the updated posterior/stage agree. Applying this argument repeatedly gives equality for every finite future string. The induced continuation laws therefore agree, with the same stopping convention. This is the known generator's property. The trained teacher is tested for approximate reset behavior; cached tensors may still differ.

## Clean banks and preprocessing

- Each root has one sampled four-token continuation. Exactly half use the supported-query construction and half use the natural generator. Root assignment is randomized once with a separate collection RNG. This is a fixed finite training bank, not new continuations sampled at every optimizer step.
- Every available continuation prefix is also eligible as a fitting start. This implements A5's requirement that detached fresh target encodings receive supervised losses when used as examples. Starts later in a collected continuation have fewer available offsets; missing/padded targets are masked. No longer rollout is invented beyond the collected window.
- Distinct full prefixes are deduplicated for preprocessing, ridge diagnostics, and sampling fitting starts. Repeated occurrences can still act as the clean supervised target of different earlier trajectories. The global nuisance split prevents a prefix from crossing fitting/validation/test groups.
- When a continuation prefix is used as a new fitting start, its reset-balancing stratum includes any `R` already observed in that continuation. That grouping is computed from tokens for sampling/loss weighting only. The bank's scalar `reset` field continues to label its original controlled root.
- Standardization uses population standard deviation (`ddof=0`) with floor 1e-6. PCA uses scikit-learn randomized SVD, seed 17, 128 components, `whiten=False`. The fitted PCA mean is subtracted. PCA coordinate signs and axes are implementation-dependent.
- Ridge alpha candidates are `[0, .001, .01, .1, 1, 10, 100]`; zero is implemented with 1e-12 for solver stability. LSQR tolerance is 1e-5. Select by analysis-validation MSE. Report native/processed held-out recovery, including stage labels. A failed pooled/PCA source is not a statement about all raw cache tensors.
- Full clean caches are not saved per example. A small matched audit cache pair is saved during final evaluation. Feature shards retain the information required for the stated models and objectives.

## Fitting and numerics

- Analysis restarts are fixed at 101, 211, 307; combined initialization seed is `teacher_seed*1000 + restart`. Restart numbers were not specified by the proposal. Every source/family uses the same restart budget.
- Teacher initialization uses independent normal .02 matrices, zero linear biases, unit LayerNorm gains, zero LayerNorm biases, including untied token/output matrices. Learned absolute embeddings are exempt from weight decay along with token embeddings, biases, and normalization.
- Teacher weights remain FP32, with BF16 autocast for training when supported. Validation/analysis use explicit FP32 attention with TF32 disabled. The code does not use dropout, FlashAttention, `torch.compile`, or quantized weights. Numerical replay is checked on the actual device.
- Density raw parameters and three stored coordinates are FP32. Small complex matrix products/normalizations use complex128 (FP64 real parts). The positive-definite inverse-square-root identity in A3 avoids unstable eigenvector differentiation at repeated eigenvalues. No PSD projection or silent eigenvalue clipping repairs an invalid learned state.
- The **joint stored state is `(three real coordinates, observable stage, absolute position)`**. Reconstructing a complex128 2×2 matrix uses 64 bytes, but persistent coordinates use 12. Stage and position use two int64 values (16 bytes). Batched working allocations are measured separately on CUDA; CPU VRAM fields are null.
- The KL term and consistency term each average their own available offsets, exactly as A5's equation specifies. At each offset, clue/reset group means receive equal weight among groups with valid observations. Detached fresh encodings are only targets. No hidden-bit label, true belief, reset flag, clue label, final answer, or family ID is passed to the learned state update/readout.
- Density initialization uses random raw operator entries with std .15. Classical score initialization also uses std .15. The proposal does not prescribe these initialization scales. Encoder/neural-baseline linear layers use PyTorch defaults; all methods have the stipulated architecture and parameter budget.
- Check analysis validation every 100 updates; select a checkpoint/restart by the specified combined validation loss. Density is fitted first per source. Each classical restart runs at least 3,000 updates and until its synchronized optimizer/data-batch time reaches that density restart's time. Validation/I/O wall time is reported separately from measured training time. Selection can choose any validation checkpoint visited during that budget.
- Checkpoints include optimizer and data RNG state. Teacher snapshots are saved every 200 validation steps and at the end; analysis snapshots every 100 and at the end. Resume may repeat work since the last saved snapshot. Bitwise identity across devices/library versions is not promised; retain the same commit and environment.

## Final-test selection and scoring

- Final plan RNG seed is 20261021. Test nuisance families are permuted without model outcomes. First 1,024 are ordinary, next 512 long. Delay assignment cycles 4/8/12 and 24/32; each family's fair filler string uses RNG seed `family+991000`. Complete-tree membership ranks SHA-256 of `tree:FAMILY_INTEGER`, selecting 256/128 within the two cohorts.
- Both clues and reset controls are generated for each family. Every donor pair matches positions, stage, suffix, nuisance, masks, precision, and last token. Directions are separately evaluated and saved. Resampling a family keeps all its conditions together.
- Ordinary natural-data results use **every nonterminal post-clue position from naturally generated held-out episodes**, producing empirical token-frequency weighting. This is separate from the balanced/no-reset controlled cohorts. No fixed-delay mixture is labeled natural generator weighting.
- For each cache arm, all surrogate predictions are computed from that edited cache and the supplied tokens before scoring prediction errors against the edited teacher. Models are already frozen and no teacher endpoint is an input to the prediction. No model selection or fitting uses any final-test intervention.
- The teacher's old logits are deliberately left unchanged by a cache edit. At least one supplied new token is processed before a causal endpoint is scored. `teacher_step` extends the modified cache directly; it does not recompute the prefix.
- The residual-only negative control changes the saved current readout/residual information after cache write while holding the persistent cache and supplied tokens fixed. Those saved vectors are not arguments to the next step, so subsequent forced-token predictions agree. This is an architectural check, not learned causal localization.
- Signed causal effect is patched minus recipient answer-1 probability. Donor-directed effect multiplies by +1 for recipient clue 0 and −1 for recipient clue 1. This definition avoids pooling opposite directions into a misleading mean of zero. Log ratios floor only logarithm arguments at 1e-12; TV and distributions retain all mass.
- A partial arm's mean impossible mass above .01 is flagged as disrupted. A full-donor effect is a replay check, not evidence of localization. Small separate effects can coexist with redundant memory; large two-factor contrasts show interaction, not percentages of information.
- Paired family bootstraps use seed 719, 2,000 resamples and percentile 2.5%/97.5% intervals. For means, sums/counts implement exactly the whole-family resampling calculation efficiently. Median endpoints resample the full condition arrays.
- The density-specific rule requires beating **both** matched classical4 and vector3 on **both** joint3 error and intervention-effect error by the predefined relative/absolute margins and positive paired intervals within each teacher. The two-state baseline is only diagnostic. The formal conclusion additionally needs all absolute gates and all three teachers.

## Scope that remains outside this implementation

The project implements the **proposed pilot**, including controls and falsifiable gates. It does not reproduce every cited paper, implement the unrelated generators from Riechers et al., automatically verify novelty, or infer a unique semantic meaning for matrix entries. It does not fit a physical potential field or assume quantum physics inside the transformer. Those are different studies and are not components of this PDF's fixed methodology.

Run files record Git/package/hardware provenance and hashes of chosen checkpoints. A hash is an audit aid, not a cryptographic barrier to an experimenter changing the program. Formal claims still depend on following the recorded protocol.
